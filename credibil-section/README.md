# Credibil - двухколоночная секция

Откройте `index.html` в браузере.

## Состав

- HTML, CSS и inline SVG в одном файле.
- Географический контур Молдовы встроен как SVG paths.
- Точечное заполнение сделано через SVG pattern и clipPath.
- Щит и галочка полностью векторные.
- Анимация подключена через Motion 12.43.0 с CDN.
- При недоступном CDN страница сохраняет внешний вид и функциональность.
- Учитывается `prefers-reduced-motion`.

## Быстрая настройка

Цвета находятся в `:root` внутри `index.html`:

```css
--navy: #04132a;
--green: #2a9c6f;
--surface: #f7f3ee;
```

Плотность точек регулируется у `pattern#dotPattern` параметрами `width`, `height` и `r`.
