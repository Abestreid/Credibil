# Credibil - скролл-история

Статический демонстрационный лендинг на русском языке.

## Запуск

Откройте папку через локальный HTTP-сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Используемые технологии

- GSAP + ScrollTrigger - основной pinned-сценарий и scroll-linked анимации.
- Three.js - лёгкие пространственные слои данных в hero и финальном CTA.
- Lottie Web - микроанимация формирования отчёта.
- SVG, CSS и JavaScript - схема связей, карта Молдовы, интерактивные состояния.

## Примечания

- Все компании, лица, IDNO и события являются вымышленными.
- При `prefers-reduced-motion` сложные анимации отключаются.
- На ширине до 900 px pinned-сценарий заменяется последовательными статичными сценами.
- Для загрузки библиотек требуется интернет-соединение.
