# Credibil landing variants

Repository with five independent Credibil landing-page concepts and one standalone section example.

## Structure

- `credibil-public-landing` - static HTML/CSS/JS landing.
- `credibil-scroll-story` - static storytelling landing.
- `credibil-site-v3` - application-based landing source.
- `credibil-wow-site` - static visual landing.
- `credibil-bolt-vite` - React/Vite landing.
- `credibil-section` - standalone section example.
- `index.html` - repository landing selector.
- `FINAL_OUTPUT.zip` - original source archive.
