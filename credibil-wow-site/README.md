# Credibil Creative Landing

Адаптивный статический лендинг Credibil с использованием:

- GSAP и ScrollTrigger для scroll-анимаций;
- Lenis для плавной прокрутки;
- SVG/CSS-графики и реальных скриншотов продукта;
- desktop, tablet и mobile breakpoints;
- `prefers-reduced-motion` и базовой клавиатурной доступности.

## Запуск

Откройте `index.html` через локальный HTTP-сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Основные файлы

- `index.html` - структура и контент;
- `styles.css` - дизайн-система, адаптив и визуальные эффекты;
- `app.js` - интерактивность, поиск и анимации;
- `assets/` - оптимизированные продуктовые скриншоты и контур Молдовы.
