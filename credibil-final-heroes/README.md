# Credibil Final Heroes — React + Vite

Чистый исходный проект текущего лендинга Credibil.

## Требования

- Node.js 20+
- npm 10+

## Установка и локальный запуск

```bash
npm install
npm run dev
```

## Production-сборка

```bash
npm run build
```

Готовые файлы появятся в `dist/client`.

Для публикации на текущем адресе загрузите содержимое `dist/client` в:

```text
/credibil/credibil-final-heroes/
```

Сборка включает:

- React-приложение лендинга;
- Vite-конфигурацию;
- румынский и русский маршруты;
- Apache `.htaccess`;
- публичную карточку `/ru/companies/1004600034130/`;
- worker и тест для OpenAI Sites.
